# 003 Interaction & Spatial Design

本文档规定 Pith 的空间布局、44px 极简顶栏（Top Bar）信息架构、主动/被动显隐心智模型与宿主命名空间隔离铁律。所有宿主壳（`shells/obsidian`、`shells/web` 及未来桌面端）必须 1:1 遵循本契约。

---

## 2. 七条空间与交互硬边界（基于用户心智的秩序重构）

1. **Obsidian 宿主命名空间隔离（默认 `Pith/` 顶层目录）与自动收起原生文件树**：
   - 在非空的真实 Obsidian Vault 中，Pith 绝不能把 `ME.md`、`topics/`、`materials/`、`_cache/` 直接散落在 Vault 根目录污染用户的笔记库！**Obsidian 壳默认必须收敛在顶层 `Pith/` 目录下**（即 `Pith/ME.md`、`Pith/topics/`、`Pith/materials/`、`Pith/_cache/`，并在插件设置中允许自定义该根目录名，默认 `"Pith"`）。
   - **打开 Pith 自动收起 Obsidian 左侧文件树**：当用户打开或激活 Pith 视图时，自动调用 `app.workspace.leftSplit?.collapse()` 收起 Obsidian 原生左侧文件树边栏，将窗口空间 100% 交给 Pith。

2. **彻底废除遮挡视线的底部半透明悬浮条，所有全局控制统一收拢进 44px 极简顶栏（Top Bar）**：
   - 半透明悬浮在正文上方的底部工具栏（`opacity: 0.15`）会像脏水印一样遮挡书籍文字，**予以彻底废除**！
   - 阅读页顶栏保持 44px 极窄单行，仅容纳 5 个克制的锚点元素：
     - 左侧：`[☰]`（目录与材料抽屉） + `[‹]`（返回罗盘首页） + `标题`（单行省略）；
     - 右侧：`[实训胶囊]`（仅当 `topic.toolkits.length > 0` 时按需显现，普通阅读课题默认只放一个极轻量的次级 `+` 或收在菜单内，零学习法绑架） + `[🎧]`（听读本章图标） + `[Aa]`（排版气泡按钮） + `[◨]`（向导栏开关图标）。

3. **`[Aa]` 精致排版气泡卡片（消灭生硬的原生 `<select>` 下拉框）**：
   - 严禁在顶栏直接裸露原生的 `<select>` 控件（`Aa 中 v`、`滚动 v`）；
   - 统一收敛为一个干净的 `[Aa]` 图标按钮，点击后在按钮下方弹出精致圆角浮层卡片（`.pith-typography-popover`），内含分段胶囊按钮切换 **字号（`小 15px` | `标准 17px` | `大 20px`）** 与 **版式（`流式滚动` | `双页分页`）**，点击外部或按 `Escape` 自动收起。

4. **被动开关 vs 场景初始态（拒绝界面元素自作聪明乱弹乱跳）**：
   - **左侧目录抽屉（纯被动）**：仅在点击左上角 `[☰]` 时滑出，选完章节、点击抽屉外区域或按 `Escape` 立即收起，鼠标移到屏幕左边缘绝不误触弹出。
   - **右侧向导侧栏（按场景意图定初始态，完全尊重用户开关）**：
     - 在**首页（罗盘总览）**，用户在规划与对话，向导栏可展开；
     - **刚从首页进入阅读页开始读书时，右侧向导栏默认收起（占 0px），让主阅读舞台 100% 居中撑满**！
     - 只有当用户**主动框选文字点击「💬 问向导」**，或**手动点击右上角 `[◨]` 图标**时，右侧向导栏才平滑展开；一旦用户手动切换了开关状态，在当前会话内记住用户的选择，绝不自动乱关乱开。

5. **顶栏伴读播控条（Chrome 内联，零正文遮挡）+ 高品质语音 Fail-Closed**：
   - 点击顶栏 `[🎧]` 开启连续伴读（仅朗读 `data-prose="true"` 正文，自动跳过代码块/表格/图片）；
   - 播放激活时，在顶栏右侧或紧贴顶栏正下方展开一条轻巧的播控条（`[⏸ 暂停 | 1.0x | 跳回朗读处 | ✕ 关闭]`），属于外框 Chrome，**永远不遮挡半个正文字**；
   - 当前朗读句呈现鼠尾草绿温和底色与下划线（`.pith-speech-active`），未连接高品质神经网络 TTS（Kokoro / 云端）时严格 Fail-Closed 弹出 2 秒自动褪去的轻量 `.pith-toast-tip`。

6. **Readest 级翻页手势统一 + 框选温润荧光黄高亮**：
   - 双页分页模式下，`wheel`（防抖节流）= `ArrowUp/Down/Left/Right` = `PageUp/PageDown` 统一按屏翻页；
   - 选区高亮 `<mark>` 使用温润荧光笔黄（`rgba(235, 204, 102, 0.38)` + `1.5px solid #c59b38` 底边）。

7. **视觉跟随宿主主题 + 霞鹜文楷书卷排版**：
   - 工作区表面与边框继承宿主 CSS 变量（`--background-primary`, `--background-secondary`, `--background-modifier-border`, `--text-normal`），正文统一采用霞鹜文楷衬线书卷栈（`"Garden LXGW WenKai", "LXGW WenKai", "Songti SC", "Noto Serif CJK SC", serif`）。
