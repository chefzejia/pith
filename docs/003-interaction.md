# 003 Interaction & Spatial Design

本文档规定 Pith 的空间布局、44px 极简顶栏（Top Bar）弹性工具槽、衍生音频与实心停靠播客甲板（Docked Media Deck）、以及跨设备连续几何自适应算法（`resolveResponsiveLayout`）。所有宿主壳（`shells/obsidian`、`shells/web` 及未来桌面/移动端）必须 1:1 遵循本契约。

---

## 2. 跨设备连续几何自适应算法（`resolveResponsiveLayout` · 拒绝死板像素断点）

Pith 不依赖死板的 `@media (max-width: 768px)`，而是根据 **Pith 容器自身的实时可用宽 $W$、高 $H$、长宽比 $R = W / H$ 与字号 $F$** 连续计算空间形态（支持直板手机、折叠屏展开方屏、iPad 分屏、Obsidian 窄窗格与桌面超宽屏）：

### 法则 A：工作区「左右分栏 vs 底部/侧边抽屉」判定（`canSplitGuide` & `sheetMode`）
只有同时满足以下 3 个几何充要条件时，右侧向导（Guide）才允许以「右侧并排分栏（`split-right`）」存在：
1. **宽度充裕**：$W \ge 420\text{px} + W_{\text{guide}} = \mathbf{740\text{px}}$（确保扣除 320px 向导栏后，正文至少保留 25 个汉字的舒适行宽）；
2. **非瘦长竖屏比例**：$R = W / H \ge \mathbf{0.85}$；
3. **垂直高度底线**：$H \ge \mathbf{480\text{px}}$。

- **手机竖屏（$R < 0.85$ 或 $W < 600\text{px}$）**：**严禁左右并排分栏**！`sheetMode = "bottom-sheet"`，向导、实训工坊与 `[Aa]` 排版菜单统一从屏幕底部上滑弹出圆角半屏/全屏卡片（Bottom Sheet），符合单手大拇指直觉。
- **手机横屏（$H < 480\text{px}$）或窄方屏（$W < 740\text{px}$）**：`sheetMode = "overlay-drawer"`，以右侧浮层抽屉形式按需滑出，不挤压正文排版宽度。
- **折叠屏展开方屏（如 $780 \times 860, R \approx 0.91$）与桌面/平板横屏（$W \ge 740\text{px}, R \ge 0.85, H \ge 480\text{px}$）**：`canSplitGuide = true, sheetMode = "split-right"`。在折叠屏上开启向导时，天然形成左 460px 单页看书 + 右 320px 向导伴学的“左书右师”双页笔记本体验！

### 法则 B：书本正文「单栏 vs 双页并排（Two-Page Spread）」黄金比例判定（`canDoubleColumn`）
设扣除已展开右侧分栏后的主舞台净宽高为 $(W_{\text{stage}}, H_{\text{stage}})$，长宽比为 $R_{\text{stage}} = W_{\text{stage}} / H_{\text{stage}}$。
只有同时满足以下 3 个条件时，才允许开启左右双栏并排（`canDoubleColumn = true`）：
1. **双栏最小行宽**：$W_{\text{stage}} \ge 2 \times 420\text{px} + 96\text{px} = \mathbf{936\text{px}}$（保证每栏至少容纳 24 个汉字）；
2. **黄金长宽比**：$R_{\text{stage}} = W_{\text{stage}} / H_{\text{stage}} \ge \mathbf{1.15}$（舞台必须明显宽于高，**严禁在接近正方形的折叠屏 $R \approx 0.9$ 上硬切出两条面条状窄栏**！）；
3. **最小垂直行数**：$H_{\text{stage}} \ge \mathbf{520\text{px}}$（防止手机横屏切成火柴盒矮栏）。

- **动态联动效应**：当用户在笔记本窗口（如 $1150 \times 800$）收起向导栏时，$W_{\text{stage}} = 1150 \ge 936$ 且 $R_{\text{stage}} = 1.44 \ge 1.15$，展现双页并排；当用户点开右侧 320px 向导栏时，$W_{\text{stage}}$ 变为 $830 < 936$，算法实时感知并**自动将左舞台平滑切回舒适的单页排版**，避免文字被挤成细条！当 `canDoubleColumn === false` 时，`[Aa]` 菜单中的“双页分页”按钮自动禁用或置灰提示“当前窗口宽度/比例适合单栏阅读”。

### 法则 C：触控热区与安全区适配
- 在粗指针设备（`coarsePointer: true`）或手机形态下，所有顶栏与播客甲板交互按钮最小点击热区自动提升至 **`44px × 44px`**，底部停靠栏与 Bottom Sheet 自动应用 `padding-bottom: env(safe-area-inset-bottom)`。

## 3. 七条交互硬边界

1. **Obsidian 宿主命名空间隔离（默认 `Pith/` 顶层目录）与自动收起原生文件树**：
   - Obsidian 壳默认收纳于 `Pith/` 目录下（`Pith/ME.md`, `Pith/topics/`, `Pith/materials/`, `Pith/_cache/`），打开视图时自动调用 `leftSplit.collapse()` 收起 Obsidian 左侧文件树。
2. **44px 极简顶栏 + 单一弹性工具胶囊槽（`[✦ 工具名 · N ▾]`）**：
   - 无论 Agent 为当前课题动态注入了 1 个还是多个 Dojo 工具，顶栏永远只占用 **1 个聚合胶囊槽位**（1 个时显示 `[✦ 费曼复述]`，多个时显示 `[✦ 影子跟读 · 2 ▾]` 点击切换），绝不排成一排按钮挤爆顶栏。
3. **PC 端离线音频资产与实心停靠播客甲板（`.pith-media-deck`）**：
   - 当打开的材料包含音频文件（`.mp3/.m4a/.wav/.ogg`，无论是原生物料还是 PC 端离线合成后同步到手机端的播客音频）或正在进行 TTS 伴读时，底部自动停靠实心播客控制条（含播放/暂停、时间进度条、`↺15s / 15s↻`、倍速 `0.75x~2.0x`、A-B 区间循环与关闭按钮），与字幕/正文 `.pith-speech-active` 同步高亮。
4. **`[Aa]` 精致排版气泡卡片**：分段胶囊切换字号与单/双栏版式（EPUB 书本仅提供「单栏」与「双栏」两种单屏翻页版式，不提供流式滚动；仅长文提供滚动），告别裸露 `<select>`。
5. **右侧向导栏挂载与默认收起**：在 Obsidian 壳中向导挂载至原生右侧栏（`getRightLeaf` + `rightSplit`），进入阅读页默认收起让位主视觉，召唤或手动开启后按课题记忆偏好。
6. **Readest 级翻页手势统一 + 纯净框选悬浮条 + 听读前置守卫**：
   - 彻底移除易误触的“▶ 从此句朗读”；框选悬浮条仅在选中非空文本时弹出 `[ 高亮 | 记笔记 | 问向导 | 复制 ]`，普通单击页面绝不弹出任何悬浮按钮；
   - `🎧 听读本章` 必须做前置校验：当当前章节无有效可读正文段落（如纯封面/版权页）或 TTS 语音服务未就绪（`checkHealth` 未通过且无衍生音频）时，置灰禁用或友好提示，严禁裸发请求弹出 `ECONNREFUSED`。
7. **视觉跟随宿主主题 + 霞鹜文楷书卷排版**。
