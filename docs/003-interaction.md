# 003 Interaction & Spatial Design

本文档规定 Pith 的空间布局、导航信息架构（IA）、Dojo 悬浮 Dock 与正文伴读交互铁律。所有宿主壳（`shells/obsidian`、`shells/web` 及未来桌面端）必须 1:1 遵循本契约，严禁在正文中堆砌顶部杂物栏。

---

## 2. 六条交互硬边界（纠正历史体验缺陷）

1. **目录与多文件导航统一归入「左侧弹出抽屉（Left Navigation Drawer）」**：
   - **触发按钮必须在左上角**（紧贴返回/品牌标志右侧的 `[☰]` 目录图标），抽屉从**左侧边缘**滑出；严禁按钮在右上角或抽屉从右侧弹出。
   - **砍掉正文上方的多文件水平 Tab 条与 Markdown 顶部内嵌导览链接墙**：一个课题绑定多个材料文件时，文件切换与章节目录（TOC）合并在同一个左侧导航抽屉中（上方文件切换、下方当前文件章节树）。正文第一行直接就是文章标题，头顶零杂物。
2. **Stage 主功能区与 Dojo 统一收拢为「底部悬浮感应条（Bottom Floating Dock）」**：
   - 砍掉正文左上方突兀的 `[分句伴读]`、`[挂载跟读]` 死按钮；
   - Stage 级伴读与已挂载的 Dojo 工具统一收拢在主舞台**正下方的悬浮胶囊条（Bottom Dock）**中：平时静止阅读时自动弱化隐藏，不挡视线；当鼠标移向舞台底部或伴读/实训正在进行时平滑浮现。
3. **整篇正文连续伴读 +「从选中句起读」+ 非正文轻量 Tip**：
   - **核心需求是连续朗读当前整篇文章的正文（Prose Only）**，而非碎片化只读选中词。分句器自动跳过代码块（`<pre>`）、Frontmatter、纯符号行与表格元数据，只朗读自然语言正文。
   - **微反应跟随**：朗读进行中，当前正在朗读的正文句子呈现温和的呼吸底色/下划线微反应（`data-speech-active="true"`），跨页时自动翻页。
   - **主动起读与非正文 Tip**：用户在正文中点击或选中某句正文并触发“从这里开始朗读”时，游标立即从该句起连续往下朗读整篇；若用户点选的是代码块、公式或非正文区域，原地浮出 **2 秒自动褪去的轻量 Toast Tip**（*“非正文内容，已跳过伴读”*），绝不用生硬的 `alert()` 弹窗打断心流。
4. **Readest 级翻页手势统一（滚轮 = 上下方向键 = 翻页）**：
   - 在按屏分页阅读模式下，**鼠标滚轮（Wheel）**、**上下方向键（`ArrowUp / ArrowDown`）**、**左右方向键（`ArrowLeft / ArrowRight`）** 与 **`PageUp / PageDown`** 行为 100% 统一为**翻上一屏 / 下一屏**（带防抖节流，防止触控板惯性一次连滚十页）。
5. **框选悬浮条（Selection Popover）专注局部选区动作**：
   - 鼠标框选文字时，选区上方浮出轻量悬浮条：`[ 🟡 高亮 | 📝 记笔记 | 💬 问向导 | ▶ 从此句朗读 ]`。
6. **右侧向导栏（Guide Sidebar）支持彻底关闭 + 纯图标开关 + 主舞台自适应**：
   - 右上角开关**只用纯图标按钮**（不写冗余的“向导/园丁”文字标签，悬浮 `title` 提示即可）；
   - 用户关闭右侧栏（或在设置中关闭 `guide-acp` 插件）后，右侧区域彻底收起占 0 像素，中间主视觉舞台（Stage）自动平滑撑满全宽（自适应单栏/双栏居中），绝不强迫不需要 AI 的用户留着空白侧栏。
7. **视觉跟随宿主主题（Host-Native Theme Inheritance · 拒绝生硬自带纸色割裂）**：
   - 严禁像早期旧版那样在右侧栏或主画布强行写死 `#f3ede1` 暖黄纸色（导致在 Obsidian 白色或暗黑界面里出现左右割裂的“两张皮”丑态）！
   - 阅读工具栏、左侧目录抽屉、右侧向导栏、设置页及普通正文**100% 默认继承宿主的 CSS 变量体系**（`--background-primary`、`--background-secondary`、`--background-modifier-border`、`--text-normal`、`--text-muted`、`--text-faint`、`--text-accent`、`--interactive-accent`，复用 `ganfan-garden/styles.css:60-89` 打磨成熟的宿主跟随规则）；仅在独立 Web 壳无外部宿主时，由 `:root` 提供与 Obsidian 默认浅色/暗色一致的基础回退变量。
