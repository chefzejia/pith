# Pith · 记忆与提取子系统（Subsystem: Memory & Retrieval）

> **目标**：构建基于情境关联与感官锚点的深度提取引擎，让知识不再是静态存储，而是可动态激活的经验。
> **核心逻辑**：基于「情境编码理论」，记忆的提取质量取决于存储时的情境线索（Contextual Cues）丰富度。

---

## 1. 核心模型

### 1.1 感官锚点 (Sensory Anchoring)
除了文本锚点，系统将采集以下维度：
*   **思维流 (Thought Flow)**：写作或阅读时的思维速度与逻辑跳跃性。
*   **情境线索 (Contextual Cues)**：当时的背景高亮色、特定 UI 布局、甚至是用户的设备状态。

### 1.2 记忆宫殿拓扑 (Memory Palace Topology)
将所有的 `Topic` 和 `Material` 映射到一个非线性的三维拓扑图上。距离不仅仅由语义相似度决定，还由「提取路径的难易度」决定。

---

## 2. 关键功能

### 2.1 记忆热身 (Memory Priming)
在用户进入某个旧课题时，系统自动重现当初记录时的环境线索（如显示当时的高亮片段、恢复当时的侧边栏布局），通过「情境重现」降低提取难度。

### 2.2 提取路径诱导 (Retrieval Path Induction)
在费曼复述遇到困难时，系统引导用户回溯到「存储该概念时的情境」，通过提供提取线索而非直接给出答案，模拟大脑自然的提取过程。

---

## 3. 实现路径

*   **数据采集**：扩展 `WorkspaceStore`，在写入记录时自动附带 `SensorySnapshot`。
*   **存储接口**：定义新的拓扑存储格式，支持基于 `Semantic + Contextual` 的双重向量查询。
