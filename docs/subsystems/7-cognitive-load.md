# Pith · 认知负荷管理子系统（Subsystem: Cognitive Load Management）

> **目标**：在 Pith 环境内实现用户认知负荷的实时监控与动态调节，防止认知过载。
> **核心逻辑**：基于认知负荷理论（CLT），通过主动的信息过滤、逻辑简化与「认知热身」减轻工作记忆压力。

---

## 1. 核心模型

### 1.1 认知负荷三级模型
*   **内在负荷 (Intrinsic Load)**：由材料本身的复杂性决定。通过「知识拆解」插件调节。
*   **外在负荷 (Extraneous Load)**：由 UI 交互、碎片信息决定。通过「视觉降噪」与「信息流控制」调节。
*   **相关负荷 (Germane Load)**：有助于构建图式的负荷。通过「费曼反馈」与「主动重构」引导。

---

## 2. 核心功能

### 2.1 动态认知脚手架 (Cognitive Scaffolding)
当系统检测到用户对复杂概念的反复查询时，自动调用 `scaffolding_plugin`，将长难文本重构为简约的拓扑逻辑图。

### 2.2 认知心跳包 (Cognitive Heartbeat)
在用户切换课题时，自动生成「心跳总结」，包含：
- **前置态**：上一次工作的逻辑出口。
- **目标态**：当前课题的起点。
- **偏差调整**：识别用户思维流的变化，协助快速切入。

---

## 3. 实现路径

*   **指标定义**：通过 ACP 工具调用的频率、笔记产生速度、上下文切换间隔定义 `CognitiveMetrics`。
*   **介入点**：集成在 `src/workbench/navigation.ts`（上下文切换）与 `src/plugins/stage-reader/index.ts`（文本呈现）。
