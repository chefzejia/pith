## 1. 双场景空间架构：首页统一立项台 vs 课题内五区工作台

Pith 的所有宿主壳（[`src/shells/obsidian/`](../../src/shells/obsidian/)、[`src/shells/web/`](../../src/shells/web/) 与 [`src/shells/dsh/`](../../src/shells/dsh/)）100% 共享同一份 `src/workbench/` 界面。为了避免首页与课题内入口打架，系统在空间上严格区分为 **「首页：课题看板与统一立项台」** 与 **「课题内：五区工作台」** 两个场景：

### 1.1 场景一：首页课题看板与唯一统一立项台（`Compass & Unified Intake` · [`compass.ts`](../../src/workbench/compass.ts)）

首页不展开右侧聊天边栏（零视觉分裂），在页面中央顶部提供**万物皆可投喂的唯一立项台（Unified Intake Box）**：

```text
+---------------------------------------------------------------------------------------+
| Pith                                                                            [⚙]   |
+---------------------------------------------------------------------------------------+
| 课题看板                                                                              |
| ┌─ 统一立项与投喂台 (Unified Intake · 支持任意课题意图 / 任意文件 / 本地代码仓) ────┐ |
| │ [ 输入你想探索的课题（如：深入理解 DSH 仓库架构 / 练经济学人发音），或直接放资料… ]│ |
| │ [ ＋ 放文件 (书籍/文档/音视频/代码) ]  [ 📁 绑定本地 Git 仓库 ]  (已选附件胶囊区)  │ |
| │                                              [ 直接开启 → ]  [ ✨ 请向导拆解立项 ] │ |
| └───────────────────────────────────────────────────────────────────────────────────┘ |
| ┌─ 下一步 · 15 分钟焦点 (Focus Recommendation) ─────────────────────────────────────┐ |
| │ 精读《01-核心拓扑.md》并用费曼工具复述 HostPort 边界              [ 继续探索 → ]  │ |
| └───────────────────────────────────────────────────────────────────────────────────┘ |
| 探索中 (N)  [ 带封面/工具标签/下一步建议/笔记计数的书卷卡片网格 .pith-topic-grid ]    |
| 已沉淀 (M)  [ 克制优雅的水平归档列表 .pith-settled-list ]                             |
+---------------------------------------------------------------------------------------+
```

- **三条无缝立项路径**：
  1. **直接投喂显式文件（EPUB / PDF / Markdown / 音视频 / 任意代码文本）**：无需填写繁琐表单，自动净化书名、提取封面、按启发式规则预挂载默认 `Toolkit`（如外文挂 `interline`、音视频挂 `shadowing`、中文/代码挂 `feynman`），立即创建课题并进入 `Stage`；
  2. **输入庞大课题意图或绑定本地 Git 仓库 + 点击 `[ ✨ 请向导拆解立项 ]`**：创建课题（若填写了本地 Git 仓库路径则校验并绑定 `commitSha` 快照，预挂载 `feynman`），进入课题工作台后**自动展开右侧向导栏并立即发送首条拆课指令**，由向导扫描仓库/背景、生成《`00-课程大纲.md`》与《`01-第一讲.md`》直接渲染到左侧 `Stage`；
  3. **输入标题 + 点击 `[ 直接开启 → ]`**：离线/无 Agent 时 0 延迟创建课题进入工作台。

### 1.2 场景二：课题内五区空间拓扑（Five-Zone Spatial Topology · [`view.ts`](../../src/workbench/view.ts)）

进入具体课题后，工作台严格划分为 **5 个互斥的物理区域（Zones）**，严禁控件跨区侵占或遮挡正文画布：

```text
+---------------------------------------------------------------------------------------+
| [Zone 1: 44px 极简顶栏 Top Bar]                                                       |
| [☰ 目录] [‹ 返回]  课题标题 · 当前材料   ‹ 1/N ›  [🛠 工具胶囊 ▾] [🎧] [Aa] [? 向导] [+]|
+-----------------------------------------------------------+---------------------------+
| ▲ (点击 [☰] 从左侧滑出导航抽屉 .pith-left-drawer：        | [Zone 4: 右侧向导栏 Guide]|
| │  合并展示【材料文件列表 + 可折叠目录树 TOC】，          |  • 顶栏切换：             |
| │  平时完全收起占 0px，正文头顶绝不放文件 Tab 条！)       |    [ 对话 | 笔记 N ]      |
|                                                           |  • 动态快捷胶囊区         |
| [Zone 2: 主视觉舞台 Primary Stage (flex: 1 · 纯净零遮挡)] |    (基础槽 + Toolkit 槽)  |
|                                                           |  • 对话气泡 & 选项胶囊    |
|   • 书卷/讲义舞台 (stage-reader)：衬线排版 / 多栏分页     |    或 笔记卡片列表        |
|   • 时间轴舞台 (stage-timeline)：媒体画面 + 同步台词流    |  • 底部共用输入区：       |
|                                                           |    [ 选区引用预览 ]       |
|   ┌─ 2a. 框选悬浮条 Selection Popover (仅划选非空正文浮现)┐|    [ 消息框 + 🎙️ + 发送 ] |
|   │      [ 🟡 高亮 | 📝 记笔记 | 💬 问向导 | 📋 复制 ]   │|  (直接阅读时默认收起；    |
|   └──────────────────────────────────────────────────────┘|   拆课立项进入时自动展开) |
|                                                           |                           |
|   ┌─ 2b. Toolkit 原位 UI Protocol 覆盖层 ────────────────┐|                           |
|   │  • 行间双语 (interline)：段落下方直接长出译文行      │|                           |
|   │  • 影子跟读 (shadowing)：句级慢放/循环/录音回放对比  │|                           |
|   │  • 费曼复述 (feynman)：目标段原位遮罩与内联阐述框    │|                           |
|   └──────────────────────────────────────────────────────┘|                           |
+-----------------------------------------------------------+---------------------------+
| [Zone 3: 底部唯一准入区 · 实心停靠播客甲板 Docked Media Deck (.pith-media-deck)]      |
| [▶/⏸]  01:24 / 08:45  ━━━━━━●────────────  [↺15s] [15s↻] [1.0x] [A-B] [跳回朗读处] [✕]|
+---------------------------------------------------------------------------------------+
```

### 五区准入硬边界

1. **Zone 1（44px 极简顶栏）**：
   - 左侧依次为 `[☰ 目录与材料抽屉]`、`[‹ 返回课题看板]`、课题/章节标题；
   - 右侧依次为：分页器 `< 1/N >`（仅按屏分页书籍显示）、**工具槽按钮 `#open-dojo`**（已挂载 `Toolkit` 时显示当前工具名如 `🛠 影子跟读 ▾`，未挂载时显示低调 `🛠` 供用户随时点击开启/管理 `Toolkit`）、伴读开关 `🎧`、排版菜单 `Aa`、向导开关 `?`、补充材料 `+`、设置 `⚙`。
   - 点击 `[Aa]` 或 `#open-dojo` 时，轻量控制菜单紧贴顶栏右下方近源展开，**严禁跑到屏幕底部或左下角弹出**。
2. **Zone 2（主视觉舞台 Stage & 左侧目录抽屉）**：
   - 课题下多文件切换（如《`00-课程大纲.md`》、《`01-核心拓扑.md`》与原书）及章节目录树统一收纳在左侧滑出抽屉 `.pith-left-drawer` 中。
   - 框选非空正文时，选区上方弹出 `[ 高亮 | 记笔记 | 问向导 | 复制 ]` 四键悬浮条。
3. **Zone 3（内容正下方唯一准入区：`.pith-media-deck`）**：
   - **内容正下方区域唯独只有音频播放控制条（`.pith-media-deck`）允许进入**！当材料含音频或正在执行 TTS 伴读时，在 Flexbox 底部**实心停靠**（挤压上方阅读容器高度，零遮挡正文）。
4. **Zone 4（右侧向导栏 Guide）**：
   - 普通阅读进入时默认收起（占 `0px`）；通过首页 `[ ✨ 请向导拆解立项 ]` 进入或点击 `?` / `问向导` 时自动展开，并按 `topicId` 独立记忆开合状态。

## 2. `Toolkit` 的多点位空间注入矩阵（Multi-Slot Toolkit Protocol）

不同 `Toolkit` 按其 `UI Protocol` 分别投射到工作台的 **4 个挂载点**：

| 挂载槽位 | 1. 输入降噪 (`interline`) | 2. 程序性声学跟练 (`shadowing`) | 3. 生成式复述 (`feynman`) |
| :--- | :--- | :--- | :--- |
| **① 顶栏工具槽与 CRUD 菜单**<br>*(Top Bar & Toolkit Popover)* | 顶栏显示 `[🛠 行间双语]`；近源菜单支持切换 `[ 原文 \| 行间双语 \| 译文主显 ]` 及勾选增删课题工具 | 顶栏显示 `[🛠 影子跟读]`；近源菜单支持切换激活工具或勾选增删课题工具 | 顶栏显示 `[🛠 费曼复述]`；近源菜单支持开启当前段复述或勾选增删课题工具 |
| **② Stage 画布原位 `UI Protocol`**<br>*(In-Place Stage Overlay)* | **段落正下方内嵌译文行**：在每个 `[data-prose="true"]` 块内底部插入 `.pith-interline-subtitle[data-prose="false"]` | **目标句原位四阶镜头 + 声学闭环条**：在 `.pith-cue` 或段落原位展开：1) `[ 意群拆解 \| 原文 \| 骨干词 \| 盲听诊断 ]`；2) **`[▶ 播放本句]`、`[🐢 0.75x 慢听]`、`[🔁 单句循环]`**；3) `🎙️` 录音转写 + **`[🔊 听我的录音]`** 原声对比 + 原位 `<mark>` 漏词标亮 | **目标段原位遮罩与阐述条**：在画布目标段落原位将其平滑折叠遮罩（“合上原文”），紧贴下方内联展开阐述框（支持打字与 `🎙️` 语音输入）及 `[提交复述并请向导追问]` |
| **③ 底部播客甲板联动**<br>*(Media Deck Sync)* | 译文块携带 `data-prose="false"`，甲板 TTS 伴读自动跳过译文 | 点击 `[▶ 播放本句]` / `[🔁 单句循环]` 自动驱动甲板音频定位到该句 `startSec..endSec`（或合成该句语音），录音时自动静音原声（`guided-follow` 边放边录除外） | 实训阐述与录音期间保持甲板音频静默 |
| **④ 右侧向导栏联动**<br>*(Guide Sidebar Integration)* | - | 向导快捷栏动态注入 `[分析跟读]` 胶囊；支持将漏词对齐记录一键存为 `practice` 笔记 | 向导快捷栏动态注入 `[费曼深水区追问]` 胶囊；提交复述后直接携带 `evaluationRubric` 发往右侧向导触发**三明治苏格拉底追问** |

## 3. 跨设备连续几何自适应与宿主主题继承

1. **连续几何自适应（[`resolveResponsiveLayout`](../../src/plugins/stage-reader/pagination.ts)）**：根据容器实时净宽、高宽比与指针类型动态切换向导栏形态（`"split-right"` / `"overlay-drawer"` / `"bottom-sheet"`）及最大可读栏数（1~3 栏）。
2. **100% 跟随宿主主题变量**：统一消费宿主 CSS 变量与明暗自适应语义色（探索态 `--pith-sage`、沉淀态 `--pith-clay`），严禁调用阻塞式 `window.alert()`。
