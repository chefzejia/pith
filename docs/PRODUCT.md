# Product Definition

> **We used all human wisdom to train AI. Pith uses AI's training pipeline to train you.**
> **全人类都在拿智慧训练大模型；Pith 借大模型的方法，训练你自己。**

## 产品定位

- **要解决的问题**：Super Agent 时代，外部产出的边际成本趋近于零，信息噪音撕裂人恒定而稀缺的注意力。瓶颈回到人自己身上：只靠向 AI 许愿跳过思考，或满足于「看懂 AI 的总结就算掌握」，大脑的参数没有更新，最终丧失领导 AI 的判断力。
- **做法**：把训练大模型的管线反过来用在人身上。输入是任何值得投入注意力的对象（代码仓库、名校公开课、外文原著、论文、播客音视频、乐谱），不限于电子书。你带来的材料不够时，向导优先从顶尖大学的公开课和经典教材里，只取回答你问题的那几讲。

  | 训练阶段 | 人的对应 | Pith 的模块 |
  | :--- | :--- | :--- |
  | 算力调度 | 注意力只投给少数课题 | 课题看板、材料库、今日 15 分钟下一步（`nextAction`）、`ME.md` |
  | 预训练 | 读一手材料，不读二手摘要 | 舞台（`Stage`）、行间双语、神经语音伴读 |
  | 监督微调 | 熟悉你的人按你的背景拆课 | 向导（`Guide`）立项、写《`00-课程大纲.md`》与逐讲讲义、配置训练工具 |
  | 强化学习 | 自己先生成，再对照误差 | 训练工具（`Toolkit`）：影子跟读、费曼复述 |
  | 评测与合并 | 抗住反例和迁移题才算学会 | 结题门禁、《核心认知总结》、画像条目 |

- **一句话定位**：以任意材料和一个能结题的问题为起点，由向导拆课并编排训练工具，把大模型训练管线映射为人的认知内化闭环的个人注意力与自我训练系统。

## 运转模型

Pith 只有三个实体。永久的东西不装在临时的东西里，所以是课题引用材料，不是材料进课题。

| 实体 | 寿命 | 归它的东西 |
| :--- | :--- | :--- |
| **材料**（`Material`） | 永久 | 只读原始文件、仓库绑定、阅读位置、行间模式与译文缓存、课题之外记下的高亮与笔记 |
| **课题**（`Topic`） | 临时：进行中，之后沉淀或搁置 | 目标、引用的材料、讲义、与向导的对话、高亮/笔记/实训记录、训练工具、结题总结 |
| **画像**（`ME.md`） | 永久 | 你写的部分；向导的观察条目 |

四个动作里，两个需要向导 Agent：

| 动作 | 需要向导 | 结果 |
| :--- | :--- | :--- |
| 投喂 | 否 | 文件、链接、仓库进入材料库，永远成功 |
| 阅读 | 否 | 读、听、高亮、记笔记；行间译文由 Agent 生成，Agent 不可用时只有原文 |
| 立项 | 是 | 向导把一句话目标和材料变成课题；向导不可用时不能立项 |
| 结题 | 是 | 通过向导的深水区一问后沉淀，观察条目写入画像。这是向导写画像的唯一时机 |

搁置和恢复一个课题由你直接操作，不经过向导。

**课题是一个能结题的问题，不按材料数量划分。**

- 想搞懂「agent 框架怎么划分内核与插件」是一个课题，dsh、magpie、t3code、herdr 都是它的材料。
- 想「能给 dsh 提 PR」是另一个课题，只引用 dsh。两个课题共用同一份材料，各有各的讲义和对话。
- 100 本书既不是 100 个课题，也不是 1 个。它们在材料库里，等你决定投入注意力时才成为某个课题的材料。

课题只有一层。拆解由课题内的课程大纲和各讲承担，不设父子课题、文件夹或分组。

## 不做什么

- 不做多会话的通用 AI 问答客户端。一个课题只有一条对话；底层 Agent 会话每轮用完即毁。课题之外不能向向导提问。
- 不做没有向导参与的课题。投喂和阅读不需要向导，立项和结题需要。
- 不做课题的嵌套、文件夹和分组。
- 不把输入窄化为电子书阅读器，也不做替代原著和源码的自动摘要机。讲义与走读必须锚定可核对的一手坐标（`IntrinsicLocator`、`path:line`）。
- 不给费曼复述打分或评级，不显示覆盖比例，也不替你出题。反馈只有逐条对照；看完原文可以再复述一次。
- 不让向导改写你在 `ME.md` 里写的内容。
- 不在设置面板暴露底层插件开关列表。
- 不回退浏览器或系统自带的机械语音，不硬编码读取特定 Agent 的私有配置文件。

## 空间与交互规则

完整契约见 [5-spatial-ui-and-slots.md](subsystems/5-spatial-ui-and-slots.md)。

1. **三个场景**
   - **首页**：立项框、今日下一步、课题（进行中、搁置、已沉淀）、材料库。不展开向导栏。
   - **材料阅读**：从材料库打开一份材料。有舞台、高亮与笔记、行间、伴读，没有向导栏，有「以此立项」。
   - **课题内**：左侧舞台，右侧向导栏。目录列出课题自己的讲义和它引用的各份材料。
2. **立项框的分流**
   - 文件、链接、仓库路径或 GitHub 仓库链接：进材料库。只有一份时直接打开阅读，多于一份时留在首页。
   - 一句话目标（可以同时带材料）：交给向导立项。向导这一轮成功后课题才写入磁盘；失败或被你停止，不留下课题，输入回到立项框。
   - 向导未连接时，带目标的提交不可用，并给出设置入口。
3. **工具的归属**
   - 行间属于阅读控制，课题内外都能用，状态跟着材料走。
   - 影子跟读与费曼复述只在课题内可用，因为它们产生的实训记录归课题。你可以在顶栏开关，向导可以按目标增删。
4. **原位覆盖与底部唯一准入**
   - 工具不另起弹窗，直接寄生在舞台的目标段落或字幕句原位。
   - 内容正下方只允许音频播放控制条（`.pith-media-deck`）进入，实心停靠，不遮挡正文。
5. **向导栏**
   - 一轮回应里，过程逐行出现（读了哪个文件、写了哪份讲义），思考折叠；完成后过程收成一行，回复保留。
   - 运行中发送按钮变成停止。失败是对话里的一行记录，你的消息保留，可以重新请求。
   - 写入结果可点：讲义行打开讲义，画像行显示新增的那句话并可撤销。
6. **书卷版心与纯净伴读**
   - 电子书按屏分页，无横向滚动条，每章独立起页；框选非空正文时弹出选区悬浮条。
   - 伴读只朗读原文，不混读译文和代码块。

## 领域概念与不变量

| 概念 | 标识 | 定义与不变量 |
| :--- | :--- | :--- |
| **工作区** | `Workspace` | 纯文本根目录（Obsidian 壳默认在 Vault 下 `Pith/`） |
| **画像** | `Profile`（`ME.md`） | 全工作区唯一。你写的部分程序永不改动；向导只能在「向导的观察」一节增删带日期、来源课题和证据笔记的条目，只在结题时写。想让向导马上知道的事，写在你自己的部分 |
| **材料** | `Material`（`materials/material-<id>/`） | 永久。只读原始文件，或绑定一个 Git 仓库的某个提交（`externalPath` + `commitSha`）：本地仓库，或 Pith 从 GitHub 克隆的仓库。同一仓库的每个提交是一份材料，即一个版本，仓库更新时导入新版本，旧版本不变。附每个文件的阅读位置。向导生成的任何内容都不写进材料 |
| **材料库** | `Library` | 全部材料的平铺列表，标出每份被哪些课题引用。不是独立实体 |
| **课题** | `Topic`（`topics/topic-<id>/`） | 一个能结题的问题。`target` 非空；`status` 为 `exploring`、`shelved` 或 `settled`；引用零到多份材料；只能由向导创建和沉淀 |
| **讲义** | `Lesson`（`topics/topic-<id>/lessons/`） | 向导为这个课题写的《`00-课程大纲.md`》与逐讲 Markdown，归课题所有。每一讲记下写入时依据的仓库版本；课题改用新版本后，向导只重写受影响的讲 |
| **对话** | `Conversation`（`topics/topic-<id>/conversation.json`） | 每个课题一条，由回合组成；每个回合含你的消息、过程步骤、回复与结束状态 |
| **舞台与工具** | `Stage` · `Toolkit` | 舞台是呈现材料的画布。工具分两类：阅读辅助挂在材料上，训练工具挂在课题上 |
| **内在位置坐标** | `IntrinsicLocator` | 与屏幕尺寸、字号无关的稳定定位符（文本块偏移、页码、媒体秒数或代码行区间 `repo:<sha>:<path>#L<a>-L<b>`） |
| **记录与锚点** | `Note` · `SelectionAnchor` | 高亮（`highlight`）、笔记（`note`）与实训记录（`practice`）。每条记录标明是你写的还是向导写的；结题门禁只认你写的笔记与实训记录。锚点由材料（或本课题讲义）、文件、坐标和原文引用组成。课题内的记录归课题；课题外只有高亮和笔记，归材料 |
| **向导与皮肤** | `Guide` · `SurfacePersona` | 内核固定用中性词 `Guide`；界面文案由 [`DEFAULT_PERSONAS`](../src/core/types.ts) 决定 |
